# Daywell

A small, browser-based daily wellness journal for food, movement, and vitals.

## Run it

Open `index.html` in a modern browser. No install or build step is needed.

## What you can track

- Meals and snacks, including calories, protein, carbs, and fat
- Workouts, duration, effort, and optional estimated calories burned
- Weight, water, steps, sleep, and heart-rate check-ins
- Daily calorie, protein, and water guideposts
- A day-by-day journal and a rolling seven-day overview

Use the date controls on the Today page to review or add an entry to another day. Your journal and planned-item check-ins are saved in this browser on this device. Use **Goals & settings** to export a JSON backup or clear saved entries and check-ins.

The Today page also displays the workout or recovery plan and the daily meal menu for the selected weekday, based on the plan CSVs in this project. Tick completed plan items to save daily progress and view four weeks of completion history in Insights. Nutrition and calorie amounts are estimates; the meal plan is not a medical prescription. Insights also includes a four-week weight trend based on logged weight check-ins. Use **Goals & settings** to switch between the red-accented light and dark themes; your theme preference is saved in this browser.
